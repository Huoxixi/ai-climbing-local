# Community source repository

This is the local boulder application. Use boulder_local_app.py and build the frontend with --mode boulder-local.
Preserve photos, video, saved analysis and original files. Never commit user data, credentials, model weights or native runtimes.
Do not re-enable cloud APIs or import production/setter application routes. Keep the app on loopback with its instance guard.
Use synthetic fixtures for tests. Preserve all third-party license and modification notices.
Public release packages contain reviewed sources only until binary redistribution and independent Windows acceptance are complete.
