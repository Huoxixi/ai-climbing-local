# 本地 App 的架构与边界

`run-local.py` 设置无云端凭证的本地环境，在 `127.0.0.1` 上启动随机空闲端口，使用 `desktop.server.InstanceGuard` 保护同源 API、静态页面和媒体 Range 请求。桌面窗口与浏览器共用同一页面；没有独立的云端服务器。

`LocalRoot.vue` 处理 owner 身份与本地退出，`LocalApp.vue` 组织照片工作台、线路库、复盘与设置。导出时只收集这一入口实际可达的前端模块，构建模式始终为 boulder-local。

`boulder_local_app.py` 装配照片任务和复盘路由，强制 LOCAL_ONLY 与 LOCAL_REPLAY_SIMPLE。照片原件、实例对象、线路成员与状态通过文件和 SQLite 持久化。岩点识别由 Detectron2 专项模型提供候选，人确认后的轮廓与成员才用于线路保存。

复盘按保存的视频帧与时间采样运行 YOLOX 人体检测和 RTMW 关键点，结合人物跟踪与墙面配准进行坐标处理。身体各段的质量加权二维估算重心、关节角和姿态数据是工程估算。缺测断开，配准失败不假造数据；纯骨架流程显式剔除岩点接触和使用信息。

视频文件和结构化分析分开保存，恢复与播放利用既有证据，导出另存新文件。结果播放器保持两侧相同尺度，右侧重画骨架、当前接触候选与估算重心路线。基础统计和导出保留，云端专业评语、动作编辑与旧仿真入口关闭。

后端按已有 `desktop/package_scope.py` 的模块前缀与 AST 导入闭包导出。部分兼容代码仍含旧云端提供方和历史动作分析实现；它们是保存历史结果所需的共享模块，不应被解释为当前产品菜单。若新增入口，应分别审查路由、界面、数据契约和外发行为。

社区默认数据位置为 AiClimbingCommunity，避免连接到内部 App 数据。目录变化经 `desktop.storage` 校验为空目录，复制资料后切换且保留原文件。代码更新不应覆盖资料、配置或模型。

Windows 原生启动器用当前用户互斥锁避免重复打开，并提供中文失败提示。直接运行源码仍应避免多个进程共用资料；未提供跨实例自动激活。安装器自动准备独立环境和模型，校验后发布版本目录，资料保持分离；详见 INSTALLER.md。
