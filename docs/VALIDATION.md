## 空间实测

精简环境验证 B：程序及模型 **1,640,236,571 字节（1.53 GiB）**；缓存清理前约 895 MB。一次接续验证测得程序和缓存峰值 **2,535,649,410 字节**，另计约 100 MB 的解压安装资源。窗口据此取整显示安装约需 **2.5 GiB**，完成后约 **1.6 GiB**。成功后清理模型压缩包、依赖缓存及解压资源。

实测机器已有微软 WebView2，以上数字不含其新安装空间，也不含个人照片、视频、复盘结果。组件版本、文件系统及微软运行组件会影响实际大小；空间检查会扣除本版本已经准备好的文件，重试不要求再空出一整份。

完整 Torch 原先包含约 2.77 GB 的编译静态库。安装器在用户本机对官方 wheel 校验后去掉这些编译材料，降低体积；不再分发修改后的第三方 wheel。

## 修正与边界

- 公开版资料使用 AiClimbingCommunity，不自动接入内部 App 数据。
- 前端固定本地入口；旧定线与云端产品入口没有开放。
- 示例改为自绘几何 SVG，没有公开复制内部照片。
- 模型下载器兼容 end2end.onnx 位于 ZIP 根目录或子目录，保持摘要验证。
- 安装器使用固定 Windows 依赖版本；Detectron2 扩展的完整对应源码、许可证与重建说明随 EXE 提供。
- Windows 较长路径资源问题已通过把第三方完整源码改为 ZIP、移除运行时不使用的 model_zoo 配置解决。

尚未完成全新独立电脑、缺 WebView2 的实际安装、DirectML 所有显卡、所有视频格式、真实多人跟踪与专业准确率的全面验收。Windows 版本以当前机器的独立环境测试为依据；不能据此承诺所有电脑一次成功。安装器暂未取得商业代码签名。
