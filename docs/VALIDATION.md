## 修正与差异

- 社区源码启动器支持安装目录外的 AiClimbingCommunity 资料目录，不自动接入内部 App 数据。
- 前端 main.js 固定本地根入口，去掉整套生产 RootApp 的引用；界面可达模块保持同源。
- 原内部示例照片没有公开复制，改用自绘几何 SVG，并在选择时转换为 JPEG 供已有上传链处理。
- 模型下载器接受 end2end.onnx 位于压缩包根目录或子目录，保持原摘要验证。
- Python 根依赖固定，间接依赖仍由 pip 解析；测试的新环境包含 FastAPI 0.141.1、Pydantic 2.14.0 和 Starlette 1.7.0。
