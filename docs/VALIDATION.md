## 空间实测

0.1.16 默认用户目录实际安装成功，程序及模型 **1,640,660,746 字节（1.53 GiB）**，结束后整个本次缓存及准备目录均不存在；日志仅留安装窗口内存。模型及精简 Torch 复用此前已验证的官方缓存，其余依赖重新获取并安装，没有将缓存复用描述为再次完整下载。此前独立流程 C 测得解压资源、程序与下载缓存峰值 **2,605,907,183 字节（2.43 GiB）**；本次准备结束阶段观测到 **2,563,961,315 字节（2.39 GiB）**，后者不是完整峰值采样。窗口据已有峰值取整显示安装约需 **2.5 GiB**，完成后约 **1.6 GiB**。

实测机器已有微软 WebView2，以上数字不含其新安装空间，也不含个人照片、视频、复盘结果。组件版本、文件系统及微软运行组件会影响实际大小；空间检查会计算本次已经准备好的文件；最终失败后清理本次文件，重新安装从头开始。

完整 Torch 原先包含约 2.77 GB 的编译静态库。安装器在用户本机对官方 wheel 校验后去掉这些编译材料，降低体积；不再分发修改后的第三方 wheel。

## 修正与边界

- 公开版资料使用 AiClimbingCommunity，不自动接入内部 App 数据。
- 前端固定本地入口；旧定线与云端产品入口没有开放。
- 示例改为自绘几何 SVG，没有公开复制内部照片。
- 模型下载器兼容 end2end.onnx 位于 ZIP 根目录或子目录，保持摘要验证。
- 安装器使用固定 Windows 依赖版本；Detectron2 扩展的完整对应源码、许可证与重建说明随 EXE 提供。
- Windows 较长路径资源问题已通过把第三方完整源码改为 ZIP、移除运行时不使用的 model_zoo 配置解决。

尚未完成全新独立电脑、缺 WebView2 的实际安装、DirectML 所有显卡、所有视频格式、真实多人跟踪与专业准确率的全面验收。Windows 版本以当前机器的独立环境测试为依据；不能据此承诺所有电脑一次成功。安装器暂未取得商业代码签名。

## 0.1.16 清理与停止验证

- 原生 Windows Job 实际运行父/子 Python 进程，子进程持有文件；停止后父子均结束，文件可删除。
- 原生清理测试验证：锁定文件导致清理失败时归属标记保留，解锁后继续清理成功；个人资料、旧版本及预先存在的同版本 App 保留；本次已改名的新版本可回退。
- 实际 Windows COM 快捷方式测试：本次覆盖的旧链接可恢复原字节，新建链接在回退后删除。均使用独立测试目录。
- 用户本机 0.1.15 实际失败日志显示 antlr4 构建路径达到旧 Windows 路径上限。显式固定路径与缩短临时目录后，0.1.16 候选版本仍在 MSIX 规范化的长临时路径下构建失败；该次失败自动清理缓存、准备目录和本次新程序目录。这是依赖构建路径问题，没有把它当作已证实的网络故障。
- 最终实现预打包三个固定版本的原始纯 Python 依赖，全部其余依赖只允许 wheel，不在用户电脑构建源码。三个 wheel 的模块、脚本及上游许可证与固定来源核对通过；原始源码与许可证随包保留。
- 修正后的 0.1.16 原生安装控制器在默认用户目录完整安装通过，成功状态为 completed=True、cache_exists=False，准备目录不存在。随后使用该环境生成合成 H.264、执行 App 视频转换并读回验证尺寸及帧数通过；独立资料目录的真实 WebView2 照片页面检查通过。仅是当前机器验收，不扩展为所有 Windows 电脑保证。
- 解压后的用户 ZIP 只有「安装说明.txt」及「安装攀岩助手.exe」；源码包另外提供「安装指引.txt」。发布包按当前源码提交构建并提供 SHA-256。
