## 空间实测

安装流程验证 C：从实际 EXE 展开到中文路径，固定依赖独立安装；模型复用前述官方校验缓存。程序及模型 **1,640,290,652 字节（1.53 GiB）**，此前成功后的缓存目录余 **28,746 字节**的日志与锁文件；新版原生窗口在退出安装引擎后删除整个本次缓存，日志仅留内存。包含解压资源、程序和下载缓存的实测峰值 **2,605,907,183 字节（2.43 GiB）**。窗口据此取整显示安装约需 **2.5 GiB**，完成后约 **1.6 GiB**。成功后清理模型压缩包、依赖缓存，原生安装窗口还会清理展开的安装资源。

实测机器已有微软 WebView2，以上数字不含其新安装空间，也不含个人照片、视频、复盘结果。组件版本、文件系统及微软运行组件会影响实际大小；空间检查会计算本次已经准备好的文件；最终失败后清理本次文件，重新安装从头开始。

完整 Torch 原先包含约 2.77 GB 的编译静态库。安装器在用户本机对官方 wheel 校验后去掉这些编译材料，降低体积；不再分发修改后的第三方 wheel。

## 修正与边界

- 公开版资料使用 AiClimbingCommunity，不自动接入内部 App 数据。
- 前端固定本地入口；旧定线与云端产品入口没有开放。
- 示例改为自绘几何 SVG，没有公开复制内部照片。
- 模型下载器兼容 end2end.onnx 位于 ZIP 根目录或子目录，保持摘要验证。
- 安装器使用固定 Windows 依赖版本；Detectron2 扩展的完整对应源码、许可证与重建说明随 EXE 提供。
- Windows 较长路径资源问题已通过把第三方完整源码改为 ZIP、移除运行时不使用的 model_zoo 配置解决。

尚未完成全新独立电脑、缺 WebView2 的实际安装、DirectML 所有显卡、所有视频格式、真实多人跟踪与专业准确率的全面验收。Windows 版本以当前机器的独立环境测试为依据；不能据此承诺所有电脑一次成功。安装器暂未取得商业代码签名。

## 0.1.16 清理与停止验证

- 原生 Windows Job 实际运行父/子 Python 进程，子进程持有文件；停止后父子均结束，文件可删除。
- 原生清理测试验证：锁定文件导致清理失败时归属标记保留，解锁后继续清理成功；个人资料、旧版本及预先存在的同版本 App 保留；本次已改名的新版本可回退。
- 实际 Windows COM 快捷方式测试：本次覆盖的旧链接可恢复原字节，新建链接在回退后删除。均使用独立测试目录。
- 用户本机 0.1.15 实际失败日志显示 antlr4 构建路径达到旧 Windows 路径上限。新版显式固定原生安装路径并缩短依赖临时目录；不是已证实的网络故障。旧 0.1.15 失败缓存与半成品程序已按指定路径清理，没有删除完整应用或个人资料。
