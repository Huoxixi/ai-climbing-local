# Third-party sources, modifications and distribution scope

This release preserves the local boulder application and adds a Windows online installer. It is not a model training release or a copy of the internal desktop distribution. Git/source ZIP and setup EXE have different scopes.

## Source actually included

- `backend/vendor/rtmlib`: RTMPose/YOLOX preprocessing and decoding subset from https://github.com/Tau-J/rtmlib . Apache-2.0. The original LICENSE and NOTICE are included. Upstream source ZIP SHA-256: `0c21e062674e31b92218974727fe5126e4cae365abff6f243f93d37d22f16df7`. The upstream BaseTool was replaced by a local-file-only ONNX adapter with explicit CPU/DirectML settings; no downloader/viewer/telemetry initialization is included. Other retained helpers are identified as unchanged in the original NOTICE.
- Detectron2-style YAML configurations under `backend/model_assets`: Mask R-CNN/R50-FPN from https://github.com/facebookresearch/detectron2 , Apache-2.0. Local configuration sets two classes, CPU, ROI p2/p3, threshold 0.4, short edge 1200 and at most 300 candidates. Upstream license retained in `licenses/Detectron2-LICENSE`. The setup EXE includes Detectron2 Python code, Windows cp312 CPU extension, original license, complete corresponding source ZIP and native/source digests. Unused model-zoo configs are omitted from runtime; source retains them. ABI: Torch 2.8.0+cpu / TorchVision 0.23.0+cpu, MSVC 2022 x64. Rebuild directions: docs/INSTALLER.md.
- `backend/vendor/NotoSansSC-VF.ttf`: Noto CJK font, SIL Open Font License 1.1; original `NotoSansSC-OFL.txt` retained. https://github.com/notofonts/noto-cjk . Unmodified font used for Chinese labels.
- `frontend/public/fonts`: original MiSans font files from Xiaomi; embedding terms are the original vendor's terms, not GPL. Source and copyright retained in its NOTICE.md: https://hyperos.mi.com/font/en/download/ and https://hyperos.mi.com/font/en/faq/ . Files are embedded as application assets, not sold separately or converted.
- The example gallery and its synthetic SVGs have been removed. Internal sample photographs, user media and third-party login photography are not included.

## Three bundled pure Python dependencies

The setup EXE includes wheels built from the pinned original PyPI source archives for antlr4-python3-runtime 4.9.3, fvcore 0.1.5.post20221221 and proxy_tools 0.1.0. This avoids source builds and Windows temporary-path failures on the user's computer. Python modules are byte-for-byte identical to the source; the ANTLR pygrun script has only Windows line-ending conversion. Wheel packaging metadata is generated by setuptools 78.1.0 / wheel 0.45.1. Original source archives and build digests are retained under third_party_source/pure-python, with reproducible preparation and validation code in installer/prepare_pure_wheels.py and pinned provenance in installer/pure-wheels.json.

ANTLR is BSD-3-Clause, with the upstream release's full LICENSE.txt retained; fvcore is Apache-2.0. proxy_tools PyPI metadata declares MIT, but its corresponding upstream LICENSE.txt uses BSD-2-Clause and names Armin Ronacher and Jonathan Tushman. We preserve the original package metadata and the actual upstream license, rather than replacing either with the project license. The complete upstream notices are included under installer/third_party_licenses. No native extension is included in these three wheels.

## Other installed dependencies (not vendored here)

Frontend and Python packages are obtained by users from their package sources. Their licenses remain in original packages. Vue, Vite, Element Plus, Axios, FastAPI, Pydantic and ONNX Runtime use MIT; Uvicorn and pywebview use BSD-3-Clause. NumPy and PyTorch/TorchVision retain BSD and native component notices; OpenCV is Apache-2.0 and includes additional native component notices; Pillow uses HPND. Other packages in requirements-local.txt retain their original licenses, including the openai SDK used by historical compatibility code.

`imageio-ffmpeg` wrapper is BSD-2-Clause. The FFmpeg executable supplied by an installed wheel may be GPL-enabled. A redistribution of such a binary requires the exact corresponding source/build and linked-library license materials, or a compliant source offer; the wrapper license is insufficient. The internal FFmpeg source bundle was not complete, so this repository and its source ZIP do not contain FFmpeg binaries or a bundled runtime. https://github.com/imageio/imageio-ffmpeg and https://ffmpeg.org/legal.html .

Setup includes app-local CPython 3.12.14 under the PSF license (runtime/LICENSE.txt), pip 26.2.1 and its MIT/vendored notices. Python source: https://www.python.org/downloads/release/python-31214/ . Project-authored C#/Python installer code is GPL-3.0, included in the EXE payload and same release's source ZIP.

Torch is obtained from the official CPU wheel URL with fixed SHA-256. Locally the installer omits static .lib files and headers, retains DLLs, implementation and all licenses, and updates RECORD. The modified wheel is never redistributed. Installed package notices remain in place; installer/dependencies-win.txt records tested versions.

Microsoft WebView2 is downloaded only if missing, under Microsoft's conditions. Its Authenticode signature is verified before installation. No developer browser profile/runtime is copied.
