# Windows 首次安装

用户已经确认：做成完整安装包，自动准备环境和模型，用中文显示进度与失败处理方式。
目标用户是没有 Python、命令行经验的普通攀岩用户。主任务是下载一个 EXE、开始安装、打开 App。
安装使用当前用户目录，不需要用户选择技术参数；首次需要网络，后续本地计算。
数据与程序分开，重试和新版本安装不得改动已有照片、视频、账号或密钥。
平台是 Windows 10/11 x64；界面采用原生 Windows 操作型布局，继承当前 App 的黄色主按钮、白灰底色与深色文字。

失败、停止、取消都清理本次环境、模型和缓存。停止留窗口，可重新安装；取消清理后退出。保留已有 App 和个人资料；清理被占用时显示继续清理。详细日志只在窗口内存中查看，不另存残余文件。
